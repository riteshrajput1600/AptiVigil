# Implementation plan

The assignable dependency-ordered backlog is maintained in [developer-stories.md](./developer-stories.md). It breaks the supplied architecture into solo-developer stories sized for approximately 2–3 focused days, with prerequisites and acceptance outcomes.

The full scope includes MCQ, essay and coding exams; structured, live/video and coding interviews; seven role portals; a public marketing/customer-acquisition app with Home, Services, Packages, Contact and Login pages; sales-led customer onboarding (no public registration); secure account/exam/interview invitations; per-candidate and interview analytics; purchase/subscription flows; security, AI-assisted proctoring, human review, integrations and production operations. Coding execution is in scope for exams and coding interviews but has a sandbox security gate before candidate submissions can run. Optional interview recording/transcription and AI-assisted summaries require explicit notice, consent/policy, access and retention controls. AI must not autonomously decide hiring, admission, certification or misconduct outcomes. Payment providers may charge transaction fees even when all application code is open source; the platform will use hosted checkout and will not store card details. Email must never contain a permanent password; use central SSO or a scoped, expiring, single-use activation link.
